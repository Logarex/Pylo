# RNC Mobile et Pylo

Pylo contient un lien vers https://www.rncmobile.net/ et explique comment une base de correspondances communautaires peut aider à rapprocher un identifiant radio d’un site Free Mobile. Aucune donnée RNC Mobile n’est copiée ou aspirée et aucun partenariat n’est présenté comme acquis.

## Ce qui a été vérifié

Le site actuel présente des identifications de sites et des informations réseau. Les actualités renvoient vers leur Discord et la messagerie interne de leur application pour les échanges. Je n’ai pas identifié de documentation publique d’API autorisant cet usage au cours de cette recherche.

L’ancien site mentionne une licence CC BY-NC 4.0 pour son contenu. Cela ne confirme ni la licence de la base actuelle, ni une autorisation de reprise des photos ou des contributions. Il faut demander le périmètre exact avant une intégration. Une app gratuite ne suffit pas à résoudre toutes les questions de licence.

Sources consultées le 31 octobre 2026 :

- https://www.rncmobile.net/news

## Proposition de prise de contact — brouillon non envoyé

Bonjour l’équipe RNC Mobile,

Je suis étudiant et je développe Pylo, une app iPhone gratuite pour explorer les antennes et mieux comprendre le réseau mobile. Le code est disponible sur GitHub sous licence GPL-3.0.

J’aimerais faire un lien utile avec votre travail communautaire. Sur iPhone, Apple ne permet pas aux apps de lire la cellule connectée ni les mesures radio détaillées. Mon idée est donc d’aider les utilisateurs à comprendre Field Test et, quand c’est possible, à retrouver un site grâce à des correspondances vérifiées.

Est-ce que vous proposez une API ou un export que je pourrais utiliser avec votre accord ? Je cherche surtout les correspondances entre identifiants radio Free Mobile et sites, ainsi que les conditions de mise à jour, d’attribution et de réutilisation. Un lien direct documenté vers vos fiches serait aussi une bonne première étape.

Je peux vous montrer le projet et adapter l’intégration à ce qui vous convient. Je préfère en discuter avec vous avant d’intégrer quoi que ce soit à partir de votre base.

Merci pour votre travail !
